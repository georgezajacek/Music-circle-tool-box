# Composer Toolbox Unified Suite

This public repository carries the checksum-verified deployment archive for the unified single-origin Composer Toolbox architecture. The protected development and recovery source remains in the private `trinity-music-programs` repository.

The release archive contains four internal pages on one host:

- Composer Toolbox at `/`
- Circle of Threes at `/threes/`
- Circle of Infinity at `/infinity/`
- Full Circle of Time at `/time/`

No iframe or external AppDeploy-app redirect is used between those pages.
